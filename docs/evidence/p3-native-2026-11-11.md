| 验收 | 结果 | 证据 |

| T4 审批拒绝 | pass | 相同工具的申请收到 `rejected`，审批记录与 call ID 对应。无文件写入，错误结果进入模型下一轮。 |
| T4 文件沙箱拒绝 | pass | 只读模式下直接写入返回 `FS_SANDBOX_DENIED`。未发起审批，未写入文件，错误结果进入模型下一轮。 |
| L3 宿主重试 | pass | 工具成功后下一次 Responses 请求收到 503。DSH 在再次发送前记录 `llm/retry` 与 `llm/retry-started`。初次工具请求、失败请求、重试共三次 HTTP。失败和重试的请求相同，工具调用、写入和持久工具结果各一次。 |
| L3 失败流与额度 | pass | 断流前收到候选工具项，宿主重试时没有审批、工具调用或写入。确认额度限制时，宿主结束该回合且没有追加重试。 |
