## Host 与 SDK 探针

- **Host seam，pass。** 通过 npm 根导出的服务与类型装配 Cordis。按项目独立路由注册，合成登录向本地 backing 写 grant，文件权限 `0600`。目录由空列表变为 `fixture-z`、`fixture-a`，跳过 hidden 并保留顺序。模型 context、温度和默认输出上限可省。观测一次模型刷新事件，准备调用只派发一次，同路由重复注册被拒。卸载撤回路由与 flow，记录仍可由 owner 管理。此项覆盖 C1 与 L1 的局部前提。
- **SDK transport，pass。** `openai@7.55.0` 的 `Responses.ResponseCreateParamsStreaming` 类型接受 namespace、完整多轮 developer／tool history、`reasoning.encrypted_content` 的 include 和合成 reasoning 回放项。实际传入 fetch 的 JSON 与预期完全一致。Bearer、DSH 归因、固定 URL、禁用组织／项目默认值与 redirect 策略均被断言。503 只触发一次 fetch，in-flight fetch 收到 abort。此项覆盖 W1、W3、T1、L2 与 L3 的局部前提。
- **SDK 流边界，pass。** SDK 交付 completed 与 usage，也原样交付 failed 和 incomplete。只有 delta 时 EOF 可结束迭代，说明 adapter 必须维护自己的成功门槛。未知、重复终态、部分工具不可执行、消费者提前退出、usage 转换与失败诊断仍需产品 fixture。此项只覆盖 W4、W6 的 transport 观察。

## pi-ai 对照

通过已发布的 `dsh-llm-pi-ai` 配置公开 `openai-responses` 路由，经 `llm.stream`、`llm.discoverModels` 观察最终请求和 DSH chunks。探针通过意味着以下观察可重复。适用的是独立 route 与原样 npm pi-ai `1.3.0` 的组合。

| 用例 | 实测 | 对复用的影响 |
|---|---|---|
| W1 | 公共 origin、Bearer、DSH User-Agent、`store:false`、`stream:true`。503 只派发一次。 | 基本 transport 符合。 |
| W2 | `supportsMaxOutputTokens:false` 省掉请求中的 `max_output_tokens`，仍派发显式 temperature，显式 stop 在发前报 `UNSUPPORTED_OPTION`。 | 需要拒绝其他不支持的显式控制。 |
| W3 | 四个输入依次为 system、user、user、user。首条 system 仍在 wire，中途 system 更新转成 user。无 `previous_response_id`。 | 不满足 preview 和更新优先级。 |
| W4 | completed 文本为 stop，failed 和 EOF 为 error，incomplete/max-output 映射为 max-tokens。 | SIWC 成功门槛必须由专用 adapter 保证。未测试该 fixture 下的 Agent 工具调度。 |
| W5／T1 | 请求工具为裸 function。两个 namespace 同名调用交错结束时，block index 和不同 ID 保留，但两个 DSH 可执行名称都为 `lookup`。 | 需要主动 namespace 分组、严格逆映射和下一轮 call ID 对照。 |
| W6 | completed 中总 input 12、cache 5、output 8 映射为未缓存 7、cache 5、output 8，总计 20。reasoning 3 未映射，缺 usage 时产出精确零，failed 中的样例 usage 未被保留。 | 需要独立处理缺失和失败用量。 |
| C1 | 公开 discovery 拒绝 `models[]`，诊断要求 `data[]` 或 `models` 对象。 | 需要 SIWC 目录解析。 |

pi-ai 本身对官方 URL、`openai` provider 及非 `sk-` 值有特殊省字段逻辑。P0 约束为独立 route。DSH wrapper 提供 header waterfall，当前未找到适用于整个请求和工具反向路由的公开配置。决定采用专用 adapter，保留 DSH 单次 attempt、持久化和工具策略。 [DSH pi-ai 配置][dsh-pi] · [pi-ai 版本元数据][pi-npm]
