## 结果

| 场景 | 结果 | 观察 |
|---|---|---|
| Web 安装、设置页、卸载 | pass | 基座 `run-container.sh all` 经官方 CLI 安装并核对配置合成。Chromium 在插件详情打开设置插槽，owner 调用返回 Host 的离线状态。卸载后配置与依赖声明均移除。 |
| Web 不兼容版本 | pass | DSH `0.2.1-rc.4` 按 `engines.dsh` 拒绝安装。未设置豁免，拒绝后 profile manifest、锁文件及配置合成保持原样。 |
| 签名 Desktop 安装、设置页、重启 | pass | 官方应用从独立用户数据目录和 `DSH_HOME` 启动。经图形插件管理器安装并启用，核对 profile 的 tarball 引用，进入插件详情并读回 Host 离线状态。结束进程后重启应用，再次打开同一设置页。来宾已回收，实验室锁已释放。 |
| 合成账号与用量界面 | pass | P1／P2 的 28 项测试、P0 的 5 项回归、lint、类型、配置和 tarball 检查通过。固定 Chromium 覆盖中英设置、用量链接、合成限额、边线变化、模型刷新、登出和离线状态。320px 中文深色界面无水平溢出。 |
| 真实登录及模型选择 | not-run | P0 账号门待完成。真实系统浏览器交接、工作区、已授 scope、模型目录及选择器、远端撤销仍待实测。首版推理和工具闭环在 P3。 |

首轮实际宿主能挂载设置插槽，但 Client Gateway 拒绝未使用严格 codec 的参数描述。修复后 Host 与 Client 复用同一 schema。回归直接挂载发布版 Client Gateway，核对打包 Client 发出 `chatgptSiwc/settings` 并解码结果。

「管理用量」在已连接账号的订阅用量行。收到订阅限额错误时，琥珀色边线与文字同时出现。界面按当前上游可确认状态显示，剩余百分比和重置时间仍待官方数据来源。 [OpenAI 限额处理](https://developers.openai.com/siwc/token-sharing-open-source/errors-and-recovery)
